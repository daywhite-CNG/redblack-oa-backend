## 3. 修复内容复核

### 3.1 身份服务调用超时

- approval-service：使用可配置连接超时和读取超时；默认连接 `1s`、响应 `3s`。
- gateway-service：使用可配置连接超时和响应超时；默认连接 `1s`、响应 `3s`。
- approval-service 超时统一转换为 `503 DEPENDENCY_UNAVAILABLE`。
- gateway 身份回源超时拒绝受保护写请求，不继续调用下游。
- 新增 approval-service 和 gateway-service 的“不响应身份服务”自动化测试。

### 3.2 参数绑定异常

以下异常统一返回 `400 VALIDATION_FAILED`：

- 缺少 `Idempotency-Key`；
- 非数字路径 ID；
- 缺少必填 `version` 查询参数。

错误响应包含 `code`、`message`、`requestId` 和 `timestamp`，并新增3个 Web 接口测试。
